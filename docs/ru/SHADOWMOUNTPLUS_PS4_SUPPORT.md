# Поддержка PS4 в ShadowMountPlus

**Языки:** [English](../SHADOWMOUNTPLUS_PS4_SUPPORT.md) · **Русский** ·
[Содержание](README.md)

Проверенный upstream-коммит:
`8566c0294cbf37b55375602e950a0e6b6bb928d7`.
В исходной рабочей области не было исходников ShadowMountPlus или PS5 SDK.

Текущий код находит `sce_sys/param.json`, извлекает `titleId`, затем
предпочитает `titleName` для `en-US`. Он подготавливает `param.json` для
appmeta и проверяет состояние монтирования через JSON-путь. Режим converter
`current-smp` точно повторяет эти операции чтения:

- корректный JSON в UTF-8 без BOM;
- точный девятисимвольный CUSA title ID;
- `titleName` верхнего уровня и локализованный `en-US.titleName`;
- исходный `param.sfo` остаётся рядом.

Набор изменений для нативного SFO находится в
`patches/shadowmountplus-ps4-support.patch` и предназначен для применения к
проверенному upstream-снимку. Он не собирается, потому что необходимый PS5 SDK
отсутствует. Перед использованием на консоли набор должен сохранить
существующее поведение JSON для PPSA/PS5 и пройти тесты на компьютере.

Статический статус не равен runtime-статусу. Проверка на PS5 по-прежнему
обязательна. Это особенно важно для экспериментального режима DLC версии
0.2.8: он отключён по умолчанию, а успешная сборка единого образа с `PSAC`
или `PSAL` не гарантирует запуск игры либо обнаружение дополнений.
`runtime_verified=false` должен сохраняться до аппаратного испытания.

Если для выбранной распакованной игры автоматически исправляется SHA-1-футер
`npbind.dat`, изменение затрагивает только временную объединённую копию и не
расширяет статическую проверку до гарантии runtime-совместимости. Исходное
распакованное дерево остаётся неизменным.
