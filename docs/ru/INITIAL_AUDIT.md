## Проверенный путь shadPS4 и граф зависимостей

Автономная цель непосредственно компилирует следующие предоставленные
исходники под GPL-2.0-or-later:

- `src/core/file_format/pkg.cpp` / `pkg.h`: `PKG::Open`, `PKG::Extract`,
  `PKG::ExtractFiles`, title ID, флаги содержимого, обход PFS/PFSC.
- `src/core/file_format/pkg_type.cpp`: `GetEntryNameByType`.
- `src/core/file_format/psf.cpp` / `psf.h`: `PSF::Open`, типизированные
  методы чтения SFO.
- `src/core/crypto/crypto.cpp` / `crypto.h` / `keys.h`: существующая логика
  RSA/AES/PFS для FPKG.
- заголовки `pfs.h`, `common/endian.h` и `common/types.h`.

Зависимости компоновки — Crypto++ и zlib. Небольшой совместимый `IOFile` и
обёртка журналирования/assert заменяют общую инфраструктуру эмулятора. Qt,
SDL, GPU, Vulkan, эмуляция CPU, звук и код запуска игр не компилируются и не
компонуются. Член `TRP` из shadPS4 исключён только для автономной цели.
Криптографическая реализация не копировалась и не переписывалась.

В предоставленных исходниках сделаны два необходимых усиления автономной
версии: сохраняется заданный вызывающей стороной корень извлечения, а имена
файлов и каталогов dirent отклоняются при наличии абсолютных разделителей,
управляющих символов, `.` или `..`. Служебные dirent остаются допустимыми.

## Выводы и риски

- `PKG::Open` предоставляет встроенный `param.sfo` без расшифровки всего PFS.
- `PKG::Extract` поддерживает предоставленный поток FPKG/PFSC. Он не добавляет
  поддержку неподдерживаемым retail PKG; ошибки получают статус
  `unsupported_or_encrypted_pkg`.
- GUI v0.7.0 сравнивает версии через `double` и индексирует разделённый
  `CONTENT_ID` DLC без проверки длины. Ни один из этих шаблонов не используется.
- Для v0.7.0 не доказано применение tombstone-записей. Merger не придумывает
  удаления.
- Необходимые условия `DELTA_PATCH` нельзя доказать по доступным метаданным,
  поэтому явное предупреждение сохранено.
- Элементы файловой системы передаются блоками по 64 КиБ, но начальный этап
  кэширования PFS в shadPS4 всё ещё может требовать значительных ресурсов
  памяти и CPU.
