# Совместимость форматов

**Языки:** [English](../FORMAT_COMPATIBILITY.md) · **Русский** ·
[Содержание](README.md)

Результат не является переименованным PKG или непосредственным необработанным
игровым содержимым PFSC.

```text
game.ffpfsc (сжатый внешний PFS)
└── CUSAxxxxx.exfat
    ├── eboot.bin
    ├── sce_sys/param.sfo
    ├── sce_sys/param.json   # проекция совместимости current-smp
    └── остальные файлы игры
```

Внутри exFAT нет каталога `CUSAxxxxx/`. Внешний PFS содержит один вложенный
образ, что соответствует прошедшему аудит сканеру `.ffpfsc` в ShadowMountPlus.

MkPFS запускается с профилем PFS для PS5, 32-битными inode, блоками PFSC по
64 КиБ и режимом без учёта регистра. Проверка охватывает внешнюю структуру и
контрольные суммы, а также внутренний exFAT с помощью выборочного
`unpack --deep`. Извлекаются обязательные пути `eboot.bin`, `param.sfo` и
(для `current-smp`) `param.json`; их структура, размеры, TITLE_ID и метаданные
ShadowMount проверяются без второго полного прохода хеширования дерева.

Если источником была выбранная распакованная игра и в ней присутствует
`sce_sys/npbind.dat`, версия 0.2.8 проверяет его структуру и SHA-1-футер.
Несовпадающий 20-байтовый футер автоматически исправляется только во временной
объединённой копии; другие байты файла и исходное дерево не меняются.
Исправленный `npbind.dat` затем проходит выборочную проверку внутри готового
образа.

Проверка на компьютере не проверяет монтирование ядром PS5. Ожидается, что
производительность PFSC будет ниже прямого exFAT/UFS из-за ограниченной
пропускной способности декомпрессии.

Итоговый `param.sfo` — точный SFO из последнего выбранного накладываемого слоя;
`CATEGORY=gp` обновления, версия, локализованные названия и пользовательские
значения не перезаписываются значениями base-пакета. `param.json` остаётся
проекцией совместимости: каждое непустое поле `TITLE_00…29` сопоставляется с
соответствующей системной локалью, посторонние существующие поля JSON
сохраняются, а для ShadowMountPlus остаётся запасная запись `en-US`. Ненулевые
значения `USER_DEFINED_PARAM_1…4` отражаются как `userDefinedParam1…4`,
поскольку некоторые запускаемые из образа игры PS4 используют эти селекторы
для языкового или регионального состояния. Такая проекция сохраняет метаданные,
но не может гарантировать, что логика выбора озвучки каждой игры использует их.

Экспериментальный режим DLC в одном образе отключён по умолчанию. При его
явном включении `PSAC` означает DLC с данными, а `PSAL` — DLC только с
лицензией. Полученный контейнер может пройти все описанные статические
проверки, но это не гарантирует запуск игры или обнаружение DLC на PS5;
до аппаратного испытания сохраняется `runtime_verified=false`.
