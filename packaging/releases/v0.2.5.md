# PS4 FFPFSC 0.2.5

> Выбор отдельных PKG, быстрое продолжение после ошибки и управляемое сжатие.
>
> Per-PKG selection, fast recovery after errors, and configurable compression.

## Загрузки / Downloads

- `PS4-FFPFSC-v0.2.5-macos-arm64.zip` — macOS 13+, Apple Silicon.
- `PS4-FFPFSC-v0.2.5-windows-x64.zip` — Windows 10/11 x64.
- Файлы `.sha256` содержат контрольные суммы архивов.
- `.sha256` files contain archive checksums.

## Русская версия

### Добавлено

- Отдельная галочка для каждого BASE, PATCH и DLC PKG. Все поддерживаемые
  пакеты выбраны по умолчанию.
- Точные копии определяются по встроенному digest заголовка PKG и отключаются
  автоматически; разные `part1`/`part2` не считаются дубликатами.
- Выбор уровня сжатия FFPFSC от 0 до 9. MkPFS использует все доступные
  логические процессоры.
- Единый двуязычный changelog для всех версий.

### Исправлено

- Повторный запуск быстро проверяет успешно распакованные PKG по метаданным и
  продолжает только с новых, изменённых или ранее завершившихся с ошибкой
  пакетов.
- Состояние сохраняется после каждого успешного PKG и при необходимости
  восстанавливается из manifest.
- Свободное место рассчитывается только для оставшихся пакетов.
- Windows использует `%TEMP%` по умолчанию и автоматически заменяет старый
  временный путь из `AppData`.
- Удалены лишние настройки «Совместимость» и DLC; безопасные значения
  ShadowMountPlus применяются автоматически.
- Обновлено окно «О программе» на русском и английском.

### Проверено

- Полный набор Python-тестов.
- Нативные C++-тесты extractor.
- Архитектурный аудит всех Mach-O и PE-бинарников.
- Frozen doctor, MkPFS, GUI и маршрутизация временных файлов.
- Реальные split-PKG Gran Turismo 7: `part1` и `part2` имеют разные digest и
  остаются выбранными.

## English version

### Added

- An independent checkbox for every BASE, PATCH, and DLC PKG. All supported
  packages are selected by default.
- Exact copies are identified by the embedded PKG header digest and unchecked
  automatically; different `part1`/`part2` packages are not treated as
  duplicates.
- FFPFSC compression levels from 0 through 9. MkPFS uses every available
  logical CPU.
- A unified bilingual changelog for every release.

### Fixed

- A later run quickly validates successfully extracted PKGs using metadata and
  continues only with new, changed, or previously failed packages.
- State is saved after every successful PKG and recovered from the manifest
  when needed.
- Free-space estimates include only packages that remain to be extracted.
- Windows uses `%TEMP%` by default and automatically migrates the legacy
  `AppData` temporary path.
- Redundant Compatibility and DLC controls were removed; safe ShadowMountPlus
  values are applied automatically.
- Updated the About dialog in both languages.

### Verified

- Complete Python test suite.
- Native extractor C++ tests.
- Architecture audits for every bundled Mach-O and PE binary.
- Frozen doctor, MkPFS, GUI, and temporary-routing smoke tests.
- Real Gran Turismo 7 split PKGs: `part1` and `part2` expose different digests
  and remain selected.
