# PS4 FFPFSC 0.2.3

> Точный прогресс по байтам и ускоренное чтение PKG.
>
> Byte-accurate progress and faster PKG reads.

## Загрузки / Downloads

- `PS4-FFPFSC-v0.2.3-macos-arm64.zip` — macOS 13+, Apple Silicon.
- `PS4-FFPFSC-v0.2.3-windows-x64.zip` — Windows 10/11 x64.

## Русская версия

### Добавлено

- Размер каждого PKG, примерный размер игры и общий объём выбранных игр.
- Прогресс распаковки по реально записанным байтам и расчёт оставшегося
  времени.
- Одинаковые функции и оптимизации в macOS и Windows.

### Исправлено

- Ускорено чтение PKG с SMB/NAS: один файловый дескриптор и read-ahead cache
  8 MiB.
- Индикатор больше не сканирует временное дерево и не создаёт лишние копии.
- Временный каталог игры удаляется после успешной сборки.

### Проверено

- Python-тесты и smoke-тесты автономных приложений.
- Сборки macOS arm64 и Windows x64.

## English version

### Added

- Per-PKG size, approximate game size, and total selected size.
- Extraction progress based on bytes actually written, including an ETA.
- Matching features and optimizations on macOS and Windows.

### Fixed

- Faster SMB/NAS reads through one persistent file handle and an 8 MiB
  read-ahead cache.
- Progress reporting no longer scans temporary trees or creates extra copies.
- Successful builds remove their per-game temporary workspace.

### Verified

- Python tests and frozen-application smoke tests.
- macOS arm64 and Windows x64 builds.
