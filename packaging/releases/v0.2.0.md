# PS4 FFPFSC 0.2.0

> Первый публичный самодостаточный выпуск.
>
> First public self-contained release.

## Загрузки / Downloads

- `PS4-FFPFSC-v0.2.0-macos-arm64.zip` — macOS 13+, Apple Silicon.

## Русская версия

### Добавлено

- Самодостаточное GUI-приложение macOS arm64.
- Выбор отдельных PKG или рекурсивное сканирование каталога.
- Группировка BASE, PATCH и DLC по `TITLE_ID`.
- Конвейер `PKG → объединённая игра → exFAT → FFPFSC`.
- Проверка контейнера и обязательных игровых файлов.
- Отдельные каталоги результата и временных данных; исходные PKG не изменяются.

### Исправлено

- Первый публичный выпуск; исправления продолжились в версии 0.2.1.

### Проверено

- Самодостаточная сборка macOS arm64 без внешнего Python.
- Базовые smoke-тесты GUI и конвейера.

## English version

### Added

- Self-contained macOS arm64 GUI application.
- Selection of individual PKGs or recursive directory scanning.
- BASE, PATCH, and DLC grouping by `TITLE_ID`.
- Complete `PKG → merged game → exFAT → FFPFSC` pipeline.
- Container and required-game-file verification.
- Separate output and temporary directories; source PKGs remain unchanged.

### Fixed

- Initial public release; maintenance fixes continued in version 0.2.1.

### Verified

- Self-contained macOS arm64 build with no external Python dependency.
- Basic GUI and pipeline smoke tests.
