# PS4 FFPFSC 0.2.2

> Windows x64, полная английская локализация и подробный прогресс.
>
> Windows x64, complete English localization, and detailed progress.

## Загрузки / Downloads

- `PS4-FFPFSC-v0.2.2-macos-arm64.zip` — macOS 13+, Apple Silicon.
- `PS4-FFPFSC-v0.2.2-windows-x64.zip` — Windows 10/11 x64.

## Русская версия

### Добавлено

- Первая самодостаточная сборка Windows x64.
- Полная английская локализация и переключатель **Русский / English**.
- Этап, подэтап, процент, прошедшее и оставшееся время.
- Сохранение проверенного состояния после ошибки или отмены.

### Исправлено

- Windows читает инвентарь из выбранного временного каталога, а не `AppData`.
- Тяжёлые временные данные направляются только в выбранную папку.
- Снижено потребление диска за счёт hardlink, атомарного перемещения и
  резервного копирования.
- Контрольные суммы архивов приведены к переносимому формату.

### Проверено

- Нативные macOS arm64 и Windows x64 сборки.
- Frozen GUI, worker, MkPFS и маршрутизация временных файлов.

## English version

### Added

- First self-contained Windows x64 build.
- Complete English localization and a **Русский / English** selector.
- Stage, substage, percentage, elapsed time, and estimated time remaining.
- Preservation of verified state after an error or cancellation.

### Fixed

- Windows reads inventory from the selected temporary directory instead of
  `AppData`.
- Heavy temporary data is written only below the selected folder.
- Lower disk use through hard links, atomic moves, and a copy fallback.
- Portable release checksum formatting.

### Verified

- Native macOS arm64 and Windows x64 builds.
- Frozen GUI, worker, MkPFS, and temporary-routing smoke tests.
