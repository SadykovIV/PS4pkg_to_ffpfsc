## Русская версия

### Добавлено

- Точные сообщения об ошибках сборки в GUI.
- Проверка и автоматическое исключение полностью одинаковых PKG.

### Исправлено

- Патч заменяет файл базы, даже если путь отличается только регистром.
- Устранено повторное сканирование каталога перед сборкой.
- Исправлена обработка конфликтующих BASE и PATCH.

### Проверено

- Автономная сборка macOS arm64.
- Тесты путей, дубликатов и группировки пакетов.

## English version

### Added

- Exact build error messages in the GUI.
- Detection and automatic exclusion of byte-identical PKGs.

### Fixed

- A patch replaces a base file even when the path differs only by letter case.
- Removed the duplicate directory scan before building.
- Corrected BASE and PATCH conflict handling.

### Verified

- Self-contained macOS arm64 build.
- Path, duplicate, and package-grouping tests.
