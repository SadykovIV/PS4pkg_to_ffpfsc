# PS4 FFPFSC 0.2.8

> Экспериментальный единый образ игры с DLC, безопасная подготовка без
> изменения исходных PKG и честный статус runtime-проверки.
>
> Experimental single-image game and DLC layout, safe preparation without
> modifying source PKGs, and explicit runtime-verification status.

## Загрузки / Downloads

- `PS4-FFPFSC-v0.2.8-macos-arm64.zip` — macOS 13+, Apple Silicon.
- `PS4-FFPFSC-v0.2.8-windows-x64.zip` — Windows 10/11 x64.
- Файлы `.sha256` содержат контрольные суммы архивов.
- `.sha256` files contain archive checksums.

## Русская версия

### Добавлено

- **Единый образ с DLC — экспериментально.** Выбранные дополнения можно
  подготовить внутри того же FFPFSC или raw exFAT, что base и patch. Режим
  отключён по умолчанию и включается только явно.
- **Изолированная подготовка.** Все изменения выполняются во временной рабочей
  области. Если конкретной игре нужна адаптация исполняемых файлов, изменяются
  только их staged-копии; исходные PKG и выбранное распакованное дерево
  остаются без изменений.
- **Честный runtime-статус.** Manifest отделяет проверенную структуру контейнера
  от фактической работы на PS5. Без аппаратного теста экспериментальный образ
  сохраняет `runtime_verified=false`.
- **Автоисправление `npbind.dat`.** У выбранной распакованной игры программа
  исправляет повреждённый 20-байтовый SHA-1-футер, только если вся структура и
  объявленный размер файла корректны. Меняется лишь временная объединённая
  копия; исходное дерево остаётся байтово неизменным.

### Исправлено

- `param.json` больше не ограничен искусственной записью `en-US`. Все
  присутствующие в итоговом `param.sfo` локализованные `TITLE_00…29`
  переносятся по системной таблице языков, а существующие дополнительные поля
  JSON сохраняются. Это предотвращает потерю русских, немецких и других
  локализационных метаданных.
- DLC-метаданные больше не накладываются напрямую на корень игры. Собственные
  `param.sfo`, лицензии и служебные файлы дополнения не заменяют итоговые
  base/patch-метаданные.
- Точные дубликаты DLC исключаются до формирования таблицы дополнений и
  содержимого единого образа.
- Обычная сборка base + patch остаётся поведением по умолчанию; пользователь
  не получает экспериментальное изменение игры без явного выбора.
- Данные права DLC больше не создаются как временный JSON-файл: они передаются
  локальному вспомогательному процессу только в памяти через стандартный ввод и
  не попадают в журнал или manifest.
- Сборка macOS arm64 теперь действительно совместима с заявленной macOS 13+:
  официальный Python 3.13.14 извлекается в изолированный build-cache,
  PySide6/shiboken6 закреплены на 6.9.3, а Crypto++ 8.9.0 собирается из
  проверенного архива исходников с deployment target 13.0. Финальный аудит
  останавливает выпуск при любом Mach-O с требованием более новой macOS.

### Проверено

- В эталонном наборе Beat Saber CUSA12878 найдено 246 DLC PKG; один точный
  дубликат исключён, а 245 уникальных дополнений подготовлены в одном образе.
- Тестовый FFPFSC прошёл MkPFS-проверку, глубокое извлечение и точную сверку
  всех 2 032 файлов и 277 каталогов подготовленного дерева.

> [!WARNING]
> Работа DLC остаётся экспериментальной. Успешная сборка и статическая
> проверка не гарантируют, что конкретная игра увидит DLC или запустится на
> PS5. Совместимость зависит от игры, типа DLC и её механизма обращения к
> дополнениям.

## English version

### Added

- **Single-image DLC — experimental.** Selected add-ons can be prepared inside
  the same FFPFSC or raw exFAT image as the base game and patches. The mode is
  disabled by default and is enabled only through an explicit choice.
- **Isolated preparation.** Every transformation takes place in the temporary
  workspace. If a game requires executable adaptation, only staged copies are
  modified; source PKGs and a selected unpacked tree remain unchanged.
- **Explicit runtime status.** The manifest separates verified container
  structure from actual PS5 behavior. An experimental image remains
  `runtime_verified=false` until it has been tested on hardware.
- **Automatic `npbind.dat` repair.** For a selected unpacked game, an invalid
  20-byte SHA-1 footer is repaired only when the complete structure and declared
  file size are valid. Only the temporary merged copy changes; the source tree
  remains byte-for-byte unchanged.

### Fixed

- `param.json` is no longer limited to a synthetic `en-US` entry. Every
  localized `TITLE_00…29` present in the final `param.sfo` is projected through
  the system language table while unrelated existing JSON fields are
  preserved. This prevents Russian, German, and other localization metadata
  from being discarded.
- DLC metadata is no longer overlaid directly onto the game root. Add-on
  `param.sfo`, license, and package-envelope files cannot replace the final
  base/patch metadata.
- Exact DLC duplicates are excluded before the entitlement table and
  single-image content are prepared.
- The ordinary base + patch build remains the default; an experimental game
  modification is never selected implicitly.
- DLC entitlement data is no longer materialized as a temporary JSON file. It
  is passed in memory to the local helper through standard input and is never
  included in logs or manifests.
- The macOS arm64 build now matches its advertised macOS 13+ compatibility:
  official Python 3.13.14 is extracted into an isolated build cache,
  PySide6/shiboken6 are pinned to 6.9.3, and Crypto++ 8.9.0 is built from a
  verified source archive with a 13.0 deployment target. The final audit stops
  the release if any Mach-O requires a newer macOS.

### Verified

- The Beat Saber CUSA12878 reference set contained 246 DLC PKGs; one exact
  duplicate was excluded and 245 unique add-ons were prepared in one image.
- The test FFPFSC passed MkPFS verification, deep extraction, and exact
  comparison of all 2,032 files and 277 directories in the prepared tree.

> [!WARNING]
> DLC support remains experimental. A successful build and static validation
> do not guarantee that a particular game will detect its DLC or launch on a
> PS5. Compatibility depends on the game, DLC type, and its add-on API path.
