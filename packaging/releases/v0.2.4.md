# PS4 FFPFSC 0.2.4

> Надёжная распаковка patch-PKG и корректный `param.json`.
>
> Reliable patch-PKG extraction and correct `param.json` handling.

## Загрузки / Downloads

- `PS4-FFPFSC-v0.2.4-macos-arm64.zip` — macOS 13+, Apple Silicon.
- `PS4-FFPFSC-v0.2.4-windows-x64.zip` — Windows 10/11 x64.

## Русская версия

### Добавлено

- Нормализация существующего `sce_sys/param.json` с сохранением игровых полей
  и добавлением метаданных, необходимых ShadowMountPlus.
- C++-регрессии для AES-записей с неполным последним блоком.

### Исправлено

- Устранено падение Windows extractor `0xC0000374` на некоторых patch-PKG.
- Исправлена ошибка `param.json titleId mismatch: None` для It Takes Two и
  других игр с минимальным JSON.
- Удалена завышенная повторная проверка свободного места 2,2×.
- Исправлено окружение Linux CI для GUI-тестов.

### Проверено

- C++-тесты, AddressSanitizer, It Takes Two и Gran Turismo 7.
- Самодостаточные сборки macOS arm64 и Windows x64.

## English version

### Added

- Existing `sce_sys/param.json` files are normalized without losing game
  fields, while required ShadowMountPlus metadata is added.
- Native regression coverage for AES records with a partial final block.

### Fixed

- Fixed Windows extractor crashes with code `0xC0000374` on some patch PKGs.
- Fixed `param.json titleId mismatch: None` for It Takes Two and other games
  with minimal JSON.
- Removed the overly conservative repeated 2.2× free-space check.
- Corrected the Linux CI environment for GUI tests.

### Verified

- C++ tests, AddressSanitizer, It Takes Two, and Gran Turismo 7.
- Self-contained macOS arm64 and Windows x64 builds.
